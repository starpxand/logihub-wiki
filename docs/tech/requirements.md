# Программные и аппаратные требования

## Серверная часть (production)

| Компонент | Требование |
|---|---|
| Оркестрация | Kubernetes 1.29+ (3 рабочих узла) |
| Узел кластера | 8 vCPU, 32 ГБ RAM, SSD 200 ГБ |
| СУБД | PostgreSQL 16 (primary + replica), 4 vCPU, 16 ГБ RAM, SSD 500 ГБ |
| Кэш и очереди | Redis 7 (кэш, сессии), брокер событий RabbitMQ 3.13 |
| Хранилище файлов | S3-совместимое объектное хранилище (ТТН, акты, фото) |
| Среда исполнения | Python 3.12 (FastAPI), Node.js 20 (веб-клиент, сборка) |
| Внешние сервисы | Картографический API (геокодирование, матрица расстояний), SMTP, Telegram Bot API |

## Клиентская часть

| Клиент | Минимальные требования |
|---|---|
| Веб-кабинет | Chrome 120+, Firefox 120+, Edge 120+, Safari 17+; разрешение от 1280×720 |
| Мобильное приложение водителя | Android 10+ / iOS 16+, GPS, камера для сканирования маркировки |
| Telegram-бот | Любой клиент Telegram |
| Рабочее место кладовщика | ПК или ТСД на Android, сканер штрихкодов 1D/2D |

## Нефункциональные требования

- Доступность сервиса – не ниже **99,5 %** в месяц.
- Время ответа API (p95) – не более **300 мс**.
- Обработка – до **500** одновременных активных перевозок, **50 000** заказов в месяц.
- Хранение данных о заказах – **5 лет** (требование бухгалтерского учёта).
