## Матрица RACI по ключевым частям продукта

R – исполняет, A – отвечает за результат, C – консультирует, I – информируется.

| Часть продукта | PO | Tech Lead | Backend | Frontend | UX/UI | QA |
|---|---|---|---|---|---|---|
| Бэклог и приоритеты | **A/R** | C | I | I | C | I |
| Архитектура | C | **A/R** | C | C | I | I |
| Сервисы и API | I | A | **R** | C | I | C |
| Интерфейсы | C | I | I | **R** | **A** | C |
| Качество релиза | A | C | C | C | I | **R** |
